# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

"Долги" — a client-only PWA (React 19 + Vite 8 + TypeScript) for tracking money lent to other people. There is no backend: all data lives in `localStorage`. The UI language is Russian and amounts are in BYN. The layout targets one phone resolution (Xiaomi Mi 11 Lite, 1080×2400), portrait only.

## Commands

Package manager is **pnpm**.

- `pnpm dev`: Vite dev server. The service worker is also active in dev (`devOptions.enabled` in `pwa.config.ts`, output goes to `dev-dist/`).
- `pnpm build`: `vite build`, then `tsc -b` type-check. The order matters: `vite build` generates the git-ignored `src/routeTree.gen.ts`, which `tsc` needs.
- `pnpm lint`: ESLint.
- `pnpm preview`: serves the production build.

The project has no test framework. Prettier config is in `.prettierrc` (single quotes, semicolons, width 100, trailing commas).

## Architecture

**Routing**: TanStack Router with file-based routes in `src/pages/` (set via `routesDirectory` in `vite.config.ts`, not the default `src/routes`). `src/routeTree.gen.ts` is generated by the Vite plugin and is git-ignored, so never edit it by hand. On a fresh clone it doesn't exist until `pnpm dev` (or `vite build`) has run once. Files and folders prefixed with `-` (e.g. `src/pages/debtors/-hooks/`) are excluded from routing, which lets route-local hooks live next to routes. `__root.tsx` wraps every page in `Layout`, which renders the navigation, the PIN lock overlay (`AccessControl`) and the `sonner` Toaster.

**State**: Zustand stores in `src/stores/`, each persisted to `localStorage` with the `persist` middleware. Stores have no actions inside them. They are created as `create()(persist(() => initialState))`, and mutations are exported as standalone functions that call `useXStore.setState(...)`. Selectors are plain functions `(state, arg) => ...` in `*.selectors.ts`, and components call them as `useXStore(useShallow((s) => selectX(s, id)))`. Most `select*ById` selectors **throw** when nothing is found.

How the data model fits together:
- `use-debtors-store`: debtors `{id, firstName, lastName?}`. `id` is a Latin slug of the full name (`slugifyToLatin`), so it is also the URL param in `/debtors/$debtorId`, and creating a duplicate name throws.
- `use-history-store`: the ledger. Every loan is a `HistoryItem` with a positive `amount`, and every repayment is one with a negative `amount`, both tied to a debtor by `actorId`. A debtor's balance is the sum of their history items. New items are added at the front of the list.
- `use-return-store`: optional planned return dates, keyed by `historyItemId`, used for the "upcoming returns" section, postponing and overdue counts. Partial repayment (`ReturnDebtDialog`) is blocked while a debtor still has items with a return date.
- `use-settings-store`: UI flags plus the PIN flag. The PIN's SHA-256 hash is stored separately under its own `localStorage` key. `deleteAllData()` clears every store's key and resets all stores, so a new persisted store must be added there.

`Date` fields come back from `localStorage` as strings after reload, because the default JSON storage does not revive them. Wrap values in `date-fns`/`dayjs` or `new Date()` instead of calling `Date` methods on them directly.

**Components**: `src/components/ui/` holds shadcn components (style `radix-nova`, config in `components.json`). Add new ones with the shadcn CLI rather than writing them from scratch. Feature components each get their own folder, split into `name.tsx`, `name.types.ts`, `name.constants.ts` (zod schemas, default form values, field names) and `name.utils.ts`, with a barrel `index.ts`. Forms use `react-hook-form` with zod schemas through `standardSchemaResolver`. Confirmation dialogs go through `useConfirmModal` (`src/hooks/`), whose `confirm()` returns a promise that resolves to a boolean.

**Path aliases** (in `tsconfig.json`, resolved by Vite through `resolve.tsconfigPaths`): `@/*` maps to `src/*`, `@components/*` to `src/components/*`, and `@ui/*` to `src/components/ui/*`.

**PWA**: the manifest and icons are configured in `pwa.config.ts`, and the icons themselves are in `public/icons/`.

## Code style

Do not leave comments in code (no `//`, `/** */` or JSX comments), including in new files and edits. Keep names descriptive instead.

Declare components as arrow functions (`export const Name = () => {}`). Use `function` declarations only where they are actually required.
