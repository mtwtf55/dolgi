# Долги (PWA)

Прогрессивное веб-приложение (PWA) для контроля средств, которые вы одолжили другим людям. Поддерживает установку на экран телефона как обычное приложение.

## Основные возможности

* **Полный учет займов:** создание записи с указанием заемщика, суммы, даты выдачи и планируемой даты возврата.
* **Гибкие сроки:** возможность быстро перенести дату возврата долга, если планы изменились.
* **Умные дедлайны:** секция «Ближайшие возвраты» для контроля скорых выплат.
* **Профили должников:** страница со списком всех заемщиков и отображением их общей суммы долга.
* **История операций:** детальный просмотр истории займов и выплат в общем и по каждому человеку при клике на его карточку.
* **Безопасность:** защита входа PIN-кодом или паролем для конфиденциальности данных.

## Особенности

* Дизайн адаптирован только под Xiaomi Mi 11 Lite (1080 x 2400). Соответственно и под телефоны с аналогичным разрешением
